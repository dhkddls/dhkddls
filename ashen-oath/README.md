# 잿빛 서약 — 종이 울리지 않는 마을

한국어 중세 판타지 이야기형 TRPG의 초반부와 중반부입니다. 세 출신, d20 판정, 세 가지 첫 결말, 턴제 전투, 레벨업과 세계관 기록서를 제공합니다. 초반부는 약 10–15분이며, 중반부는 반복 전투와 준비에 따라 플레이 시간이 달라집니다. 전투 중에도 자동 저장하며 모험 기록을 내려받을 수 있습니다.

## 실행

### 다운로드해서 바로 실행

이 폴더의 **`play.html`을 다운로드하고 Chrome·Edge·Firefox·Safari 같은 최신 브라우저로 여세요.** JavaScript와 CSS가 포함된 단일 파일이므로 Python·Node.js 설치나 서버 실행이 필요 없습니다. GitHub 파일 화면에서는 **Download raw file** 버튼으로 다운로드할 수 있습니다. GitHub에서 소스 파일을 보는 화면 자체가 게임 실행 화면은 아닙니다.

진행은 해당 브라우저에 저장됩니다. 이전 클라우드 테스트나 다른 브라우저의 진행은 자동으로 옮겨지지 않습니다. 파일 접근 정책으로 저장이 제한되면 게임 하단에 안내가 표시되며, 탭을 닫기 전까지 플레이할 수 있습니다.

### 원본을 수정하며 실행

별도 패키지 설치 없이 Python 3와 최신 브라우저만 있으면 됩니다.

```bash
cd /workspace/dhkddls/ashen-oath
python3 -m http.server 8000 --bind 0.0.0.0
```

브라우저에서 서버의 8000번 포트를 엽니다. 서버를 자신의 컴퓨터에서 실행했다면 `http://localhost:8000`으로 접속합니다. 클라우드 서버의 localhost는 사용자 컴퓨터에서 접속할 수 없으며 이 작업 환경은 웹 미리보기 연결을 제공하지 않습니다. 직접 플레이하려면 위의 `play.html`을 이용하세요. 개발 원본인 `index.html`은 ES 모듈을 사용하므로 HTTP 서버가 필요합니다.

### 단일 실행 파일 갱신

게임 원본을 고친 뒤 Node.js와 npm이 있는 환경에서 실행합니다. 처음 빌드할 때 고정 버전 `esbuild@0.25.5`를 npm에서 받아 사용하므로 네트워크가 필요합니다. 생성된 `play.html`은 직접 수정하지 않고 원본과 함께 저장합니다.

```bash
cd /workspace/dhkddls/ashen-oath
node build-standalone.mjs
```

## 플레이

1. 기사·서기관·길잡이 중 출신을 고릅니다.
2. 본문을 읽고 행동을 선택합니다. 필요한 d20 판정은 자동으로 진행됩니다.
3. 「여정」에서 목표와 단서, 「세계관」에서 배경, 「기록」에서 이전 선택을 확인합니다.
4. 첫 결말에서 「중반부로 떠나기」를 선택해 염로와 별무덤 주조소로 이동합니다.
5. 전투와 휴식으로 성장해 문지기를 처치합니다. 첫 결말과 중반부 종료 화면에서 기록을 Markdown으로 내려받을 수 있습니다.

## 전투와 성장

첫 늑대 전투 뒤 주조소 야영지에서 반복 전투와 휴식을 할 수 있습니다. 기본 공격은 가장 높은 능력치를 사용합니다. 결정타는 명중에 −3, 피해에 +3을 적용합니다. 응급 처치는 전투당 두 번, 기력 `4 + 현재 레벨`을 회복하며 적도 행동합니다. 후퇴는 항상 성공합니다.

**경험치 비교 기준은 플레이어 레벨입니다. 플레이어가 몬스터보다 높으면 증가하고, 낮으면 감소합니다.**

```text
배율 = clamp(1 + 0.25 × (플레이어 레벨 − 몬스터 레벨), 0.25, 2)
지급 경험치 = 반올림(몬스터 기본 경험치 × 배율)
```

같은 레벨은 100%, 플레이어가 두 레벨 높으면 150%, 두 레벨 낮으면 50%입니다. 전투 시작 시 배율을 고정합니다. 레벨이 다르면 경고와 실제 보상을 먼저 보여주며, 확인해야 전투가 시작됩니다. 취소하면 진행에 영향이 없습니다.

| 몬스터          | 권장 레벨 | 기본 경험치 | 위치             |
| --------------- | --------- | ----------- | ---------------- |
| 갈대 그림자늑대 | 1         | 50          | 염로·야영지      |
| 공허의 사냥개   | 2         | 75          | 주조소 운송로    |
| 밀랍 파수병     | 3         | 95          | 주조소 입구      |
| 메아리 기사     | 4         | 130         | 선택 전투·순찰로 |
| 보관소의 문지기 | 4         | 160         | 중반부 보스      |

누적 경험치가 **0 / 80 / 200 / 380 / 620**이면 각각 Lv.1~5가 됩니다. 레벨마다 최대 기력 +4, 모든 능력치 +1을 얻고 기력을 전부 회복합니다. 최대 레벨은 5이며 이후에도 누적 경험치는 기록합니다.

승리할 때만 경험치를 한 번 지급합니다. 패배하면 경험치 없이 기력 1로 야영지에 돌아오고, 후퇴도 경험치가 없습니다. 야영지 휴식은 무료이며 경험치 없이 기력을 전부 회복합니다. 적이 내 레벨에 맞춰 자동으로 강해지지는 않습니다.

진행은 현재 브라우저의 로컬 저장소에 저장됩니다. 계정 동기화와 서버 저장은 없습니다. 다시 시작은 확인창을 거쳐 진행을 초기화합니다. 저장소 사용이 제한되면 화면 아래에 알림이 표시됩니다. 키보드로 버튼과 대화상자를 조작할 수 있고 기록서 탭은 좌우 방향키로 이동할 수 있습니다.

## 코드 구조와 읽는 순서

각 JavaScript 파일 위쪽의 `@file` 주석에서 역할을 먼저 확인한 뒤, 생성자와 메서드 위의 설명을 따라 읽으면 됩니다. `#필드`는 객체 내부 상태, `get`은 값을 읽는 접근자, `static`은 객체를 새로 만들지 않고 클래스에서 호출하는 기능입니다. `//` 주석은 계산 과정이나 분기 이유를 설명하고, `/** ... */` 주석은 기능 단위의 설명입니다.

데이터 파일에는 장면·선택지·몬스터 필드의 뜻을, HTML·CSS에는 화면 영역과 반응형 배치의 역할을 주석으로 적었습니다. 테스트 파일에서는 공통 준비 함수와 각 검증 목적을 확인할 수 있습니다. `fixtures/v1-save.json`은 실제 저장 형식을 검사하므로 주석을 허용하지 않는 JSON을 그대로 유지합니다.

`app.mjs`의 `GameApplication`에서 시작하면 **선택 → 게임 진행 → 저장 → 화면 갱신** 흐름을 볼 수 있습니다. 각 클래스는 아래 책임만 맡으며, 상속 대신 객체 조합을 사용합니다. 게임 규칙과 저장·화면 처리를 분리해 브라우저 없이도 규칙을 검사할 수 있습니다.

| 파일                           | 클래스 / 내용                           | 책임                                               |
| ------------------------------ | --------------------------------------- | -------------------------------------------------- |
| `app.mjs`                      | `GameApplication`                       | 사용자의 행동과 게임·저장·화면 연결                |
| `engine.mjs`                   | 도메인 클래스 내보내기                  | 게임 규칙에 접근하는 공개 진입점                   |
| `domain/adventure.mjs`         | `Adventure`                             | 장면 이동, 선택 제한, 단서, 기록, 저장 상태 복구   |
| `domain/character.mjs`         | `Character`                             | 출신, 능력치, 기력, 소지품                         |
| `domain/skill-check.mjs`       | `SkillCheck`                            | d20 판정과 성공·실패 계산                          |
| `domain/combat-session.mjs`    | `CombatSession`                         | 한 전투의 적 기력·턴·응급 처치·승패 관리           |
| `domain/experience-policy.mjs` | `ExperiencePolicy`                      | 경험치 배율·레벨 경계·레벨 경고 규칙               |
| `ui/combat-view.mjs`           | `CombatView`                            | 전투 행동·결과·레벨업 표시                         |
| `save-repository.mjs`          | `SaveRepository`                        | 브라우저 저장소 접근, 손상된 저장과 접근 실패 처리 |
| `journal-exporter.mjs`         | `JournalExporter`                       | 모험 기록을 Markdown 문자열로 변환                 |
| `ui/game-view.mjs`             | `GameView`                              | 하위 화면 조합, 대화상자와 이벤트 연결             |
| `ui/character-view.mjs`        | `CharacterView`                         | 캐릭터 정보 표시                                   |
| `ui/story-view.mjs`            | `StoryView`                             | 장면·판정·선택지 표시                              |

| `data/`                        | `origins.mjs`, `scenes.mjs`, `lore.mjs` | 출신·장면·세계관 데이터                            |

`index.html`과 `style.css`는 화면 구조와 스타일을 담당합니다. 직접 작성한 SVG 풍경을 사용하며 외부 폰트·이미지·CDN 의존성은 없습니다. 상세 세계관은 `WORLD.md`에 있습니다. **결말 스포일러를 포함합니다.**

### 게임 규칙 사용 예시

```js
import { Adventure } from "./engine.mjs";

const adventure = new Adventure("scribe");
adventure.choose("lantern");
console.log(adventure.scene.title); // 빈 의자에 앉은 손님
console.log(adventure.character.health); // 10

const snapshot = adventure.toSnapshot();
const restored = Adventure.fromSnapshot(snapshot);
```

`choose()`는 해당 모험 객체를 갱신합니다. 별개 분기를 살펴보려면 `clone()`으로 복제합니다. 내부 진행 필드는 `#` 비공개 필드로 관리하며, 기록·소지품·저장 스냅샷은 복사본을 반환합니다. `SkillCheck`의 난수 생성기와 `SaveRepository`의 저장소 공급자를 주입하면 테스트에서 주사위와 저장 권한을 제어할 수 있습니다.

### 이야기 수정 위치

- 초반 장면: `data/scenes.mjs`. 중반 장면과 첫 결말별 연결: `data/midgame-scenes.mjs`. 선택지는 `id`, `label`, `detail`, `next`처럼 의미가 드러나는 객체 필드로 작성합니다.
- 몬스터 능력치·권장 레벨·기본 경험치: `data/monsters.mjs`. 레벨 경계와 배율: `domain/experience-policy.mjs`.
- 출신 설명과 능력치: `data/origins.mjs`.
- 게임 안 세계관: `data/lore.mjs`. 상세 진행자 설정은 `WORLD.md`.

브라우저 저장 키 `ashen-oath.v1`은 유지하고, 새 기록은 v2 형식으로 저장합니다. 이전 v1 기록은 레벨 1·경험치 0으로 복구해 이어서 플레이할 수 있습니다. 저장된 기력·경험치·적 HP를 그대로 믿지 않고 선택과 전투 주사위 기록을 재생해 재계산합니다. 새 기록은 선택지 ID를 사용합니다. 이전 v1 기록은 `label`로 행동을 식별하므로 기존 초반부 문구를 바꿀 때는 별도 마이그레이션이 필요합니다.
