# 잿빛 서약 — 종이 울리지 않는 마을

한국어 중세 판타지 이야기형 TRPG의 완결 캠페인입니다. 서리여울의 실종 사건에서 시작해 별무덤 주조소와 왕도의 제9보관소까지 이어집니다. 각 장면의 현재 목표·사건 요약·등장인물 안내와 세 장의 장면 일러스트를 제공합니다. 세 출신, d20 판정, 전술 턴제 전투, Lv.1~8 성장, 두 단계 최종 보스와 세 가지 최종 결말을 제공합니다. 첫 서약·왕도 증거·출신에 따라 후일담이 달라집니다. 초반부는 약 10–15분이며 이후는 조사와 훈련 횟수에 따라 달라집니다. 전투 중에도 자동 저장하고, 진행 백업과 모험 기록을 내려받을 수 있습니다.

## 실행

### 웹사이트에서 온라인 플레이

게시 후 게임 주소는 **<https://dhkddls.github.io/dhkddls/ashen-oath/>**입니다. 설치 없이 컴퓨터·휴대폰의 최신 브라우저에서 플레이할 수 있습니다. <https://dhkddls.github.io/dhkddls/>로 접속해도 게임으로 이동합니다.

저장소 관리자가 최초 한 번 GitHub Pages를 활성화해야 합니다.

1. [저장소 Settings → Pages](https://github.com/dhkddls/dhkddls/settings/pages)를 엽니다.
2. **Build and deployment → Source**를 **Deploy from a branch**로 선택합니다.
3. **Branch**에서 **main**, 폴더는 **/(root)**를 선택하고 **Save**를 누릅니다.
4. [Actions](https://github.com/dhkddls/dhkddls/actions)에서 **pages build and deployment**가 완료된 뒤 게임 주소를 엽니다. 최초 게시에는 몇 분 걸릴 수 있습니다.

게임은 정적 HTML·CSS·JavaScript로 동작하므로 별도 서버나 비밀 키가 필요 없습니다. 이후 `main`에 올린 변경은 GitHub Pages가 자동 반영합니다. 저장소 루트의 `index.html`이 게임 폴더로 안내하고, `.nojekyll`은 Jekyll 변환 없이 원본 파일을 게시하게 합니다. 단일 실행 파일 빌드는 온라인 실행의 필수 단계가 아닙니다.

진행은 접속한 브라우저에 자동 저장됩니다. 「저장 슬롯」에는 자동 저장과 별개로 세 여정을 보존할 수 있으며, 저장·덮어쓰기·불러오기는 확인창을 거칩니다. 다운로드판·다른 브라우저의 기록이 웹사이트로 자동 이동하지는 않습니다. 옮기려면 기존 게임에서 「진행 백업」을 내려받고 웹사이트의 「불러오기」에서 JSON을 선택하세요. 계정 로그인이나 기기 간 자동 동기화는 없습니다.

### 다운로드해서 바로 실행

이 폴더의 **`play.html`을 다운로드하고 Chrome·Edge·Firefox·Safari 같은 최신 브라우저로 여세요.** JavaScript와 CSS가 포함된 단일 파일이므로 Python·Node.js 설치나 서버 실행이 필요 없습니다. GitHub 파일 화면에서는 **Download raw file** 버튼으로 다운로드할 수 있습니다. GitHub에서 소스 파일을 보는 화면 자체가 게임 실행 화면은 아닙니다.

진행은 해당 브라우저에 저장됩니다. 이전 클라우드 테스트나 다른 브라우저의 진행은 자동으로 옮겨지지 않습니다. 파일 접근 정책으로 저장이 제한되면 게임 하단에 안내가 표시됩니다. 「진행 백업」으로 JSON을 내려받아 두고, 다음 실행이나 다른 브라우저에서 「불러오기」로 이어갈 수 있습니다. 읽기용 Markdown 기록은 진행 파일로 불러올 수 없습니다.

### 원본을 수정하며 실행

별도 패키지 설치 없이 Python 3와 최신 브라우저만 있으면 됩니다.

```bash
cd /workspace/dhkddls/ashen-oath
python3 -m http.server 8000 --bind 0.0.0.0
```

브라우저에서 서버의 8000번 포트를 엽니다. 서버를 자신의 컴퓨터에서 실행했다면 `http://localhost:8000`으로 접속합니다. 클라우드 서버의 localhost는 사용자 컴퓨터에서 접속할 수 없으며 이 작업 환경은 웹 미리보기 연결을 제공하지 않습니다. 직접 플레이하려면 게시된 웹사이트나 위의 `play.html`을 이용하세요. 개발 원본인 `index.html`은 ES 모듈을 사용하므로 HTTP 서버가 필요합니다.

### 단일 실행 파일 갱신

게임 원본을 고친 뒤 Node.js와 npm이 있는 환경에서 실행합니다. 처음 빌드할 때 고정 버전 `esbuild@0.25.5`를 npm에서 받아 사용하므로 네트워크가 필요합니다. 생성된 `play.html`은 직접 수정하지 않고 원본과 함께 저장합니다.

```bash
cd /workspace/dhkddls/ashen-oath
node build-standalone.mjs
```

## 플레이

상단의 「글자 크기」에서 90%·100%·115%·130%를 선택할 수 있습니다. 본문·선택지·전투·기록·안내창의 글자가 함께 바뀌며, 이 브라우저에서 다음 접속과 새 게임에도 유지합니다. 모험 저장·슬롯·JSON 백업과는 별도로 보관합니다. 브라우저 저장소가 차단되어도 이번 접속 중에는 크기를 조절할 수 있습니다.

판정 선택지에는 현재 출신·레벨·상태 이상을 반영한 성공 확률을 표시합니다. d20의 20개 눈을 실제 판정과 같은 규칙으로 세므로 자연 1 실패·자연 20 성공이 포함되며, 확률 범위는 5~95%입니다. 미리보기는 주사위를 소비하거나 진행·상태 이상 횟수를 바꾸지 않습니다. 전투 승률을 뜻하는 수치는 아닙니다.

1. 기사·서기관·길잡이 중 출신을 고릅니다.
2. 본문을 읽고 행동을 선택합니다. 필요한 d20 판정은 자동으로 진행됩니다.
3. 「여정」에서 목표와 단서, 「세계관」에서 배경, 「기록」에서 이전 선택을 확인합니다.
4. 첫 결말에서 「중반부로 떠나기」를 선택해 염로와 별무덤 주조소로 이동합니다.
5. 전투와 휴식으로 성장해 문지기를 처치한 뒤 「왕도로 향하기」를 선택합니다. 기존 중반부 완료 저장도 이 지점에서 이어집니다.
6. 왕실 서고와 시민 광장을 조사하거나 바로 보관소를 추적합니다. 필수 장부는 본편에서 확보하며 조사 실패로 결말이 막히지 않습니다.
7. Lv.6 외곽 방어선, Lv.7 왕관의 기계, Lv.8 이름 없는 심장을 넘어 마지막 서약을 고릅니다. 보스 사이에 회복·훈련할 수 있습니다.
8. 완결 화면에서 첫·마지막 서약, 전투 승리, 증거와 인물들의 후일담을 확인합니다. 막 종료와 완결 화면에서 모험 기록을 Markdown으로 내려받을 수 있습니다.

## 전투와 성장

첫 늑대 전투 뒤 주조소 야영지에서 반복 전투와 휴식을 할 수 있습니다. 적이 **이번에 할 행동**을 먼저 확인한 뒤 대응합니다. 기본 공격은 출신·성장의 최고 기본 능력치와 상태 명중 보정을 사용합니다. 결정타는 명중에 −3, 피해에 +3을 적용합니다. 응급 처치는 전투당 두 번, 기력 `4 + 현재 레벨`을 회복하고 먼저 걸린 상태 이상 하나를 해제하며 적도 행동합니다. 기력이 가득해도 상태를 치료할 수 있습니다. 후퇴는 항상 성공합니다.

**경험치 비교 기준은 플레이어 레벨입니다. 플레이어가 몬스터보다 높으면 증가하고, 낮으면 감소합니다.**

```text
배율 = clamp(1 + 0.25 × (플레이어 레벨 − 몬스터 레벨), 0.25, 2)
지급 경험치 = 반올림(몬스터 기본 경험치 × 배율)
```

같은 레벨은 100%, 플레이어가 두 레벨 높으면 150%, 두 레벨 낮으면 50%입니다. 전투 시작 시 배율을 고정합니다. 레벨이 다르면 경고와 실제 보상을 먼저 보여주며, 확인해야 전투가 시작됩니다. 취소하면 진행에 영향이 없습니다.

| 몬스터             | 권장 레벨 | 기본 경험치 | 위치                  |
| ------------------ | --------- | ----------- | --------------------- |
| 갈대 그림자늑대    | 1         | 50          | 염로·야영지           |
| 공허의 사냥개      | 2         | 75          | 주조소 운송로         |
| 밀랍 파수병        | 3         | 95          | 주조소 입구           |
| 메아리 기사        | 4         | 130         | 선택 전투·순찰로      |
| 보관소의 문지기    | 4         | 160         | 중반부 보스           |
| 밀랍 운반체        | 4         | 160         | 왕도 골목             |
| 침묵 집행관        | 5         | 200         | 왕도 법원 지하        |
| 보관소 외곽 수호체 | 6         | 240         | 왕도 훈련·외곽 방어선 |
| 왕관의 기계        | 7         | 260         | 최종 보스 1단계       |
| 이름 없는 심장     | 8         | 340         | 최종 보스 2단계       |

누적 경험치 **0 / 80 / 200 / 380 / 620 / 950 / 1,400 / 2,000**에서 각각 Lv.1~8이 됩니다. 레벨마다 최대 기력 +4, 모든 능력치 +1을 얻고 기력을 전부 회복합니다. 초반·중반의 상한은 Lv.5이며 왕도로 향하면 Lv.8까지 개방됩니다. 상한에서도 경험치는 누적하고, 왕도 진입 시 누적량을 반영합니다. 기존 중반부 기록의 전투 수치를 바꾸지 않기 위한 구분입니다.

승리할 때만 경험치를 한 번 지급합니다. 패배하면 경험치 없이 기력 1로 해당 구간의 안전한 곳에 돌아오고, 후퇴도 경험치가 없습니다. 거점·확보한 보스 통로의 휴식은 무료이며 경험치 없이 기력을 전부 회복합니다. 최종 보스 1단계를 끝냈다면 패배·후퇴 뒤에도 2단계부터 재도전합니다. 적이 내 레벨에 맞춰 자동으로 강해지지는 않습니다.

진행은 현재 브라우저의 로컬 저장소에 저장됩니다. 계정 동기화와 서버 저장은 없습니다. 「진행 백업」은 현재 전투까지 담은 JSON을 다운로드하며 「불러오기」는 기록을 검증하고 확인창을 거쳐 교체합니다. 취소하거나 잘못된 파일을 고르면 현재 진행을 유지합니다. 파일당 최대 5MB입니다. 다시 시작은 확인창을 거쳐 진행을 초기화합니다. 저장소 사용이 제한되면 화면 아래에 알림이 표시됩니다. 키보드로 버튼과 대화상자를 조작할 수 있고 기록서 탭은 좌우 방향키로 이동할 수 있습니다.

## 행동 예고와 전술

| 적이 예고한 행동 | 실제 효과                          | 대응                                    |
| ---------------- | ---------------------------------- | --------------------------------------- |
| 일반 공격        | 기본 피해                          | 공격·회복·방어                          |
| 힘 모으기        | 이번에는 공격하지 않고 다음에 강타 | 방해 공격이 명중하면 다음 강타까지 취소 |
| 강타             | 피해 +4 · 명중 시 갈대 상처        | 방어로 피해 절반·상처 차단, 또는 방해   |
| 기억의 속삭임    | 피해 −1 · 명중 시 기억 혼탁        | 방어로 상태 차단, 또는 방해             |
| 봉인 방어        | 이번 적 방어 +3 · 공격하지 않음    | 회복·단서 활용·확정 피해 기술           |

**방어**는 이번 방어 +3, 받은 피해를 올림해 절반으로 줄이고 적의 상태 부여를 막습니다. **방해 공격**은 명중 −2, 기본 피해 절반이며 명중하면 이번 특수 행동을 끊습니다. 사용 후 다른 행동 2회가 필요합니다. 자연 20의 추가 피해는 유지합니다.

| 출신   | 기술        | 효과                                                               |
| ------ | ----------- | ------------------------------------------------------------------ |
| 기사   | 서약의 방패 | 이번 피해·적 상태 부여를 막고, 적이 공격하면 `3 + 레벨` 확정 반격  |
| 서기관 | 이름 해독   | `2 + 레벨` 확정 피해 · 다음 2행동 적 방어 −2 · 이번 특수 행동 차단 |
| 길잡이 | 그림자 걸음 | 이번 적 공격·상태 회피 · 명중 +3, 적중 피해 +2의 사격              |

출신 기술은 사용 뒤 **다른 행동 3회**, 방해 공격은 **다른 행동 2회**를 해야 다시 사용할 수 있습니다. 저장·슬롯 확인·취소는 대기를 줄이지 않습니다. 서기관의 해독이나 단서로 힘 모으기를 끊으면 다음 강타도 취소됩니다.

**단서 활용**은 전투마다 한 번, 해당 적과 관련 있는 실제 수집 단서가 있어야 합니다. 특수 행동을 끊고 이후 적 방어를 2 낮춥니다. 왕실 원본은 중앙 기계, 시민 증언과 실험 장부는 마지막 심장에 사용합니다. 봉인문·인장·운송 명령도 해당 수호체에 효과가 있습니다. 서기관의 일시 약화와 함께 적용할 수 있습니다. 조사를 놓쳐도 모든 결말에 도달할 수 있습니다.

새 전투의 보스 기력은 문지기 **40**, 왕관의 기계 **64**, 이름 없는 심장 **78**입니다. 권장 레벨과 기본 경험치·플레이어 레벨에 따른 보정 방향은 그대로입니다. 보스 사이에 회복할 수 있고, 패배·후퇴 후 재도전할 때 첫 단계를 다시 잡지 않습니다.

## 실패와 상태 이상

판정 실패는 기존의 기력 손실에 더해 세계관에 맞는 상태 이상을 남깁니다. 실패한 판정에 사용한 능력치로 종류를 정하며, 효과는 **다음** 위험 행동부터 적용합니다.

| 실패한 판정 | 상태 이상   | 이야기 판정 감소 | 전투 감소                 |
| ----------- | ----------- | ---------------- | ------------------------- |
| 무력        | 갈대 상처   | 무력 −2          | 기본 공격 피해 −2, 최소 1 |
| 통찰        | 기억 혼탁   | 통찰 −2          | 공격 명중 −2              |
| 의지        | 메아리 공포 | 의지 −2          | 방어 −2                   |

전투에서 기본 공격·결정타·방해 공격·길잡이 사격이 빗나가도 메아리 공포가 생깁니다. 자연 1뿐 아니라 명중 난이도에 못 미친 공격도 포함합니다. 기존 효과는 현재 행동의 적 반격까지 적용한 뒤 횟수를 줄이고, 새 실패 효과는 그 뒤 3회로 적용합니다.

- 이후 이야기 판정 또는 후퇴를 제외한 전투 행동 **3회** 동안 유지합니다. 다른 능력치 판정도 횟수에 포함합니다.
- 이동·전투 시작·후퇴·안내 취소·새로고침은 횟수를 줄이지 않습니다.
- 같은 상태는 강도·개수를 중첩하지 않고 남은 기간만 3회로 갱신합니다. 다른 종류는 함께 걸릴 수 있습니다.
- 응급 처치는 먼저 걸린 상태 하나를 해제합니다. 다른 상태는 이번 치료 행동에도 1회 줄어듭니다. 적의 반격은 그대로 있습니다.
- 거점·안전 통로의 휴식과 막 사이 여행은 모든 상태를 해제합니다. 레벨업은 기력만 회복합니다. 최종 후일담에서도 회복합니다.
- 상태가 적용된 능력치가 음수가 될 수 있습니다. 자연 20 성공·자연 1 실패와 이야기 기력 하한 1은 유지합니다.

전투의 「상태별 치료 도구」에는 **약초 붕대**(갈대 상처 해제와 `2 + 레벨` 회복), **이름 수첩**(기억 혼탁 해제), **동료의 호명**(메아리 공포 해제)이 각각 하나씩 준비됩니다. 같은 도구는 전투당 한 번이며, 해당 상태가 있어야 사용할 수 있습니다. 치료할 때도 적은 행동하고 다른 상태의 기간은 줄어듭니다. 공통 응급 처치 두 번은 별개입니다.

캐릭터 패널은 이야기 판정에 쓸 감소된 능력치와 상태별 남은 횟수·해제 방법을 표시합니다. 전투는 출신·성장의 최고 기본 능력치로 명중·피해를 계산한 뒤 표의 전투 감소량을 한 번 적용합니다. 전투 화면에서 현재 명중·기본 피해·방어를 확인할 수 있습니다.

## 코드 구조와 읽는 순서

각 JavaScript 파일 위쪽의 `@file` 주석에서 역할을 먼저 확인한 뒤, 생성자와 메서드 위의 설명을 따라 읽으면 됩니다. `#필드`는 객체 내부 상태, `get`은 값을 읽는 접근자, `static`은 객체를 새로 만들지 않고 클래스에서 호출하는 기능입니다. `//` 주석은 계산 과정이나 분기 이유를 설명하고, `/** ... */` 주석은 기능 단위의 설명입니다.

데이터 파일에는 장면·선택지·몬스터 필드의 뜻을, HTML·CSS에는 화면 영역과 반응형 배치의 역할을 주석으로 적었습니다. 테스트 파일에서는 공통 준비 함수와 각 검증 목적을 확인할 수 있습니다. `fixtures/`의 JSON은 이전 버전의 실제 저장 형식을 검사하므로 주석 없이 유지합니다.

`app.mjs`의 `GameApplication`에서 시작하면 **선택 → 게임 진행 → 저장 → 화면 갱신** 흐름을 볼 수 있습니다. 각 클래스는 아래 책임만 맡으며, 상속 대신 객체 조합을 사용합니다. 게임 규칙과 저장·화면 처리를 분리해 브라우저 없이도 규칙을 검사할 수 있습니다.

### 게임 규칙 사용 예시

```js
import { Adventure } from "./engine.mjs";

const adventure = new Adventure("scribe");
adventure.choose("lantern");
console.log(adventure.scene.title); // 빈 의자에 앉은 손님
console.log(adventure.character.health); // 10

const snapshot = adventure.toSnapshot();
const restored = Adventure.fromSnapshot(snapshot);
```

`choose()`는 해당 모험 객체를 갱신합니다. 별개 분기를 살펴보려면 `clone()`으로 복제합니다. 내부 진행 필드는 `#` 비공개 필드로 관리하며, 기록·소지품·저장 스냅샷은 복사본을 반환합니다. `SkillCheck`의 난수 생성기와 `SaveRepository`의 저장소 공급자를 주입하면 테스트에서 주사위와 저장 권한을 제어할 수 있습니다.

### 이야기 수정 위치

- 본문·장면별 목표·사건 요약·주요 인물: `data/story-revision.mjs`. 초반 선택지와 규칙: `data/scenes.mjs`. 중반 장면과 첫 결말별 연결: `data/midgame-scenes.mjs`. 왕도 조사·보스·최종 선택: `data/finale-scenes.mjs`. 조건별 후일담: `domain/campaign-resolution.mjs`. 선택지는 `id`, `label`, `detail`, `next`처럼 의미가 드러나는 객체 필드로 작성합니다.
- 몬스터 능력치·권장 레벨·기본 경험치: `data/monsters.mjs`. 레벨 경계와 배율: `domain/experience-policy.mjs`. 상태 이상 이름·수치·실패 대응: `data/status-effects.mjs`. 지속·해제: `domain/status-effects.mjs`.
- 출신 설명과 능력치: `data/origins.mjs`.
- 게임 안 세계관: `data/lore.mjs`. 상세 진행자 설정은 `WORLD.md`.

브라우저 저장 키 `ashen-oath.v1`은 유지하고, 새 기록은 v4 형식으로 저장합니다. 이전 v1 기록은 레벨 1·경험치 0으로 복구해 이어서 플레이할 수 있습니다. v1·v2 기록은 지난 행동을 당시 규칙으로 복구하며 이후 새 행동부터 상태 이상을 적용합니다. `debuffsFrom`은 이 경계를 보존합니다. `tacticsFrom`은 전술 도입 지점입니다. 이전 v1~v3 저장에서 이미 시작한 전투는 기존 규칙으로 끝내고, 다음 새 전투부터 행동 예고·직업 기술·전용 도구가 열립니다. 과거 선택지 ID·판정 수치·결과 문구는 유지합니다. 본문만 쉽게 고쳤으므로 예전 여정도 새 설명으로 이어집니다. 저장된 상태 이상·남은 횟수·기력·경험치·적 HP를 그대로 믿지 않고 선택과 전투 주사위 기록을 재생해 재계산합니다. 새 기록은 선택지 ID를 사용합니다. 이전 v1 기록은 `label`로 행동을 식별하므로 기존 초반부 문구를 바꿀 때는 별도 마이그레이션이 필요합니다.

### 수동 슬롯

브라우저 키 `ashen-oath.slot.1`~`.3`에 장면·전투·상태·기술 대기·치료 도구까지 보존합니다. 슬롯 저장은 자동 저장을 바꾸지 않으며, 초기화와 JSON 불러오기도 수동 슬롯을 지우지 않습니다. 취소하면 아무 변화가 없습니다. 손상된 슬롯은 불러오기만 잠그고 원본은 보존합니다. 저장 권한·용량 문제가 있으면 JSON 진행 백업을 이용하세요. 슬롯 역시 해당 브라우저·사이트에 저장되며 계정 동기화는 없습니다.
