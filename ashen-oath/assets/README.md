# 장면 일러스트

이 게임을 위해 이미지 생성 도구로 제작한 서리여울·별무덤 주조소·엘드라 왕도 그림입니다. 외부 이미지 서버를 사용하지 않습니다.

- `village.webp`: 등불을 든 네라와 여행자, 강가 마을과 멎은 종탑.
- `foundry.webp`: 은종·빈 갑옷·기억 용기가 남은 산악 주조소.
- `capital.webp`: 왕도와 그 아래 중앙 수집 장치에 도착한 여행자·리안·장례사.

생성 원본의 구도·해상도를 유지한 채 WebP 품질 84로 인코딩했습니다. 웹 버전은 이 파일을 직접 읽고, `build-standalone.mjs`는 같은 파일을 data URL로 내장합니다. 경로와 대체 텍스트는 `data/art.mjs`에서 관리합니다. 이미지 오류 시 기존 SVG가 표시됩니다.
